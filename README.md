# Embedded MCU Power & Programming Board

Custom ESP32-S3 development board designed in KiCad.

- **MCU:** ESP32-S3-WROOM-1 module
- **USB-C:** USB 2.0 receptacle for power and programming
- **ESD protection:** USBLC6-2SC6 on the USB data lines
- **Regulation:** AMS1117-3.3 regulator with bulk and decoupling capacitors
- **Controls:** two push buttons
- **Expansion:** 2x 20-pin headers

## Files

- `Micro-Controller-V1.kicad_sch`: schematic
- `Micro-Controller-V1.kicad_pcb`: PCB layout
- `MY_Footprints.pretty/`: custom ESP32-S3-WROOM-1 footprint

Open `Micro-Controller-V1.kicad_pro` in KiCad 10.
